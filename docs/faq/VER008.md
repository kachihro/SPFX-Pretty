# VER008: .yo-rc.json version differs from the packages

**Area:** Versions · **Needs you**

## Why it matters

Dependencies were upgraded by hand; "yo @microsoft/sharepoint" would add new components with the old version.

## How to fix

1. Update "version" in .yo-rc.json to match @microsoft/sp-core-library.
