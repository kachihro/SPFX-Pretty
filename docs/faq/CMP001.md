# CMP001: Toolbox title is not nice

**Area:** Toolbox · **Auto-fix available**

## Why it matters

This is the name authors see in the web part toolbox. "HelloWorld" or "team-news-web-part" looks unfinished.

## Where

`<WebPart>.manifest.json → preconfiguredEntries[].title.default`

## How to fix

1. Apply the suggested title, or type your own.
2. Tip: start with your company name (e.g. "Kachihro News") so authors can search for all your web parts.

### Before

```json
"title": {
  "default": "HelloWorld"
}
```

### After

```json
"title": {
  "default": "Kachihro Hello World"
}
```
