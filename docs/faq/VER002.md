# VER002: SPFx packages on mixed, pre-release or ranged versions

**Area:** Versions · **Needs you**

## Why it matters

All @microsoft/sp-* packages must be exactly the same version. Ranges (^) and release candidates cause hard-to-trace build problems.

## How to fix

1. Set every @microsoft/sp-* package to the same exact version (no ^ or ~).
2. npm install, then rebuild.
