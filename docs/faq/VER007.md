# VER007: serve.json uses the SharePoint Online workbench

**Area:** Versions · **Needs you**

## Why it matters

The hosted workbench retires on 01/12/2026.

## How to fix

1. Debug on a real page with the developer toolbar instead, and update initialPage in config/serve.json.
