# CMP002: Toolbox description is a placeholder

**Area:** Toolbox · **Guided fix (asks you)**

## Why it matters

Shown as the tooltip in the toolbox. "HelloWorld description" does not help anyone choose.

## Where

`<WebPart>.manifest.json → preconfiguredEntries[].description.default`

## How to fix

1. Click "Write the description…" and type one sentence about what authors get.
