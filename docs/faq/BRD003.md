# BRD003: Hard-coded colour in SCSS

**Area:** Branding · **Auto-fix available**

## Why it matters

Fixed colours ignore the site theme and section backgrounds.

## How to fix

1. Apply the fix to use a theme token.

### Before

```
color: #0078d4;
```

### After

```
color: "[theme:themePrimary, default: #0078d4]";
```
