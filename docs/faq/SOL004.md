# SOL004: Developer details are missing

**Area:** App Catalog · **Guided fix (asks you)**

## Why it matters

The App Catalog app details page shows the developer, website, privacy and terms links. Teams and Viva Connections require them.

## Where

`config/package-solution.json → solution.developer`

## How to fix

1. Set your details once in Settings → SPFX Pretty → Developer (or developer in .spfxprettyrc.json).
2. Then click the fix - it fills every project the same way.

### Example

```json
"developer": {
  "name": "Kachihro",
  "websiteUrl": "https://…",
  "privacyUrl": "https://…",
  "termsOfUseUrl": "https://…",
  "mpnId": "Undefined-1.24.1"
}
```
