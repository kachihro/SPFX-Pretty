# BRD006: Inline colour in TSX

**Area:** Branding · **Needs you**

## Why it matters

Inline colours ignore the theme (especially dark section backgrounds).

## How to fix

1. Use semanticColors from the theme (e.g. theme.semanticColors.bodyText) or a CSS variable.
