# VER001: Behind the latest SPFx

**Area:** Versions · **Needs you**

## Why it matters

Older versions miss fixes, security updates and new features; very old ones use the unsupported gulp toolchain.

## How to fix

1. Run "SPFX Pretty: Version Check & Upgrade Assessment" for a step-by-step plan with effort.
2. For file-by-file changes: npx -p @pnp/cli-microsoft365@latest m365 spfx project upgrade --toVersion <latest> --output md
