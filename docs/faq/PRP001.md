# PRP001: Property declared but never used

**Area:** Properties · **Guided fix (asks you)**

## Why it matters

Unused properties are still saved with every instance on every page, and confuse whoever maintains the code.

## How to fix

1. If it is truly unused: Apply Fix removes it from the props interface (and the manifest defaults).
2. If it should be used: read it in render() or add a property pane field for it.
