# DEF006: Generator sample properties are still registered

**Area:** Defaults · **Needs you**

## Why it matters

The Application Customizer generator registers testMessage "Test message" - users get an alert on every page.

## Where

`sharepoint/assets/elements.xml and ClientSideInstance.xml → ClientSideComponentProperties`

## How to fix

1. Replace ClientSideComponentProperties with your real settings, or "{}".
2. Remove the Dialog.alert sample code from the extension.

### Before

```
ClientSideComponentProperties="{&quot;testMessage&quot;:&quot;Test message&quot;}"
```

### After

```
ClientSideComponentProperties="{}"
```
