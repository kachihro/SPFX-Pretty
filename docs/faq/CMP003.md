# CMP003: No toolbox icon, or still the default

**Area:** Toolbox · **Auto-fix available**

## Why it matters

Every new web part uses the "Page" icon, so yours look like every other custom web part.

## How to fix

1. Pick a brand-coloured SVG icon (initials or a type glyph), or
2. choose a Fluent icon name (officeFabricIconFontName), e.g. "News", "People", "Calendar".
