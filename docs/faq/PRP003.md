# PRP003: Property pane field targets a missing property

**Area:** Properties · **Needs you**

## Why it matters

Usually a typo - the field saves to a property the code never reads.

## How to fix

1. Correct the name in PropertyPaneXxx('name', …) or add the property to the props interface.
2. Nested targets like "tile.size" are fine when "tile" is declared.
