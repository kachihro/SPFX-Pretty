# SOL013: Solution version and package.json version differ

**Area:** App Catalog · **Guided fix (asks you)**

## Why it matters

The App Catalog shows the solution version, while web parts (manifest "version": "*") report the package.json version. Mismatched numbers confuse support.

## How to fix

1. Bump the lower one so they match (SPFX Pretty never suggests a downgrade).
2. Bump package-solution.json version every release so SharePoint sees an update.
