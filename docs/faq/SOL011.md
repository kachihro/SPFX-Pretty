# SOL011: App icon file not found

**Area:** Icons · **Auto-fix available**

## Why it matters

iconPath points at a file that is not in ./sharepoint, so packaging fails or no icon shows.

## How to fix

1. iconPath is relative to ./sharepoint - move the file there, or
2. click the fix to upload/generate an icon at that path.
