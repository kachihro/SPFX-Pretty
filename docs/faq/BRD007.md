# BRD007: Fluent UI v9 without FluentProvider

**Area:** Branding · **Needs you**

## Why it matters

v9 controls use the default Microsoft blue instead of the site theme.

## How to fix

1. Wrap your root component in <FluentProvider theme={…}> built from the SharePoint theme.
