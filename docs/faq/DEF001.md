# DEF001: Default property value is a raw name

**Area:** Defaults · **Auto-fix available**

## Why it matters

preconfiguredEntries.properties are the values every new web part starts with - "HelloWorld" shows on the page straight away.

## How to fix

1. Apply the suggested value, or set a sensible default in the manifest.

### Before

```json
"description": "HelloWorld"
```

### After

```json
"description": "Hello World"
```
