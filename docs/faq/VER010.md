# VER010: @types/react does not match React

**Area:** Versions · **Needs you**

## Why it matters

Type definitions for a different React major give misleading errors (or hide real ones).

## How to fix

1. Install @types/react and @types/react-dom for the same major, and update any resolutions/overrides pin.
