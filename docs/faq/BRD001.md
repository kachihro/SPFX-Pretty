# BRD001: No theme variant support

**Area:** Branding · **Auto-fix available**

## Why it matters

Without supportsThemeVariants the web part renders a white box on coloured section backgrounds.

## How to fix

1. Set "supportsThemeVariants": true, then handle theme changes (BRD002).
