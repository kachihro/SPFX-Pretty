# VER011: Legacy ReactDom.render on React 18

**Area:** Versions · **Needs you**

## Why it matters

ReactDom.render runs React 18 in React 17 mode - you miss concurrent features and get console warnings.

## How to fix

1. Create one root per web part: this._root = createRoot(this.domElement); this._root.render(element);
2. In onDispose: this._root?.unmount();
