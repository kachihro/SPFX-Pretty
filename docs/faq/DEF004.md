# DEF004: Package file name is generic

**Area:** Defaults · **Auto-fix available**

## Why it matters

Without paths.zippedPackage the file uploaded to the App Catalog is "ClientSolution.sppkg" - the Name column shows that.

## How to fix

1. Apply the fix to name it after your app, e.g. solution/kachihro-project.sppkg.
