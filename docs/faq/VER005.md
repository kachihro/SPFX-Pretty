# VER005: Node version not declared or unsupported

**Area:** Versions · **Guided fix (asks you)**

## Why it matters

Without engines.node or .nvmrc people build with whatever Node they have, causing "works on my machine" problems.

## How to fix

1. Apply the fix to add engines.node, or add a .nvmrc file.
2. Match the Azure DevOps NodeTool task to the same version.
