# BRD002: Theme changes not handled

**Area:** Branding · **Needs you**

## Why it matters

The web part opts in to section backgrounds but never reads the theme, so colours stay fixed.

## How to fix

1. Override onThemeChanged() and push semanticColors into CSS variables.
2. Run "SPFX Pretty: Show Theme-Aware Web Part Snippet" for code tailored to your web part.
