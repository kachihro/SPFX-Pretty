# VER006: Gulp toolchain

**Area:** Versions · **Needs you**

## Why it matters

Gulp is unsupported from SPFx 1.24 - upgrading means migrating to Heft (gulpfile customisations move to Heft plugins).

## How to fix

1. Follow Microsoft's gulp → Heft migration guide.
2. Change pipeline commands from gulp bundle/package-solution to npm run build.

[Microsoft Learn](https://learn.microsoft.com/sharepoint/dev/spfx/toolchain/migrate-gulptoolchain-hefttoolchain)
